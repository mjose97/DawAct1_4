# Actividad 1.3 - Práctica con GitHub y Markdown

Bienvenido a mi repositorio de la **Actividad 1.3**.  
En esta práctica estoy aprendiendo a usar _Markdown_ para crear documentación clara y estructurada en **GitHub**.


![Logo Markdown](markdown.png)

---

## Descripción del proyecto

Este repositorio forma parte de la asignatura de _Entornos de Desarrollo_.  
Su objetivo es aprender a:

- Editar un archivo `README.md`  
- Usar **Markdown** correctamente  
- Subir archivos a un repositorio en **GitHub**

Más información sobre Markdown en la guía oficial: [Markdown Guide](https://www.markdownguide.org/basic-syntax/).
